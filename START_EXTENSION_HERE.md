## 🐛 Troubleshooting

### Extension not showing?
```
1. Reload Cursor (Cmd+Shift+P → "Reload Window")
2. Check Extensions panel (Cmd+Shift+X)
3. Look for "Motion Autoya" in list
```

### Library not loading?
```
1. Check animation-presets.json exists
2. Click refresh button in panel
3. Verify path in settings
```

### Preview not opening?
```
1. Click on animation (not category)
2. Try right-click → "Preview Animation"
3. Check console for errors
```
